# painting.json schema

The single source of truth for everything painting-specific. The four pages all `fetch('painting.json')` at load and render against it.

## Top-level fields

```jsonc
{
  "id":           "string, lowercase slug. Used as the DZI base name and a few derived filenames. No spaces.",
  "site_name":    "string. Site brand (shown in nav top-left, footer).",
  "site_tagline": "string. Brand subtitle, shown as small text after the name.",
  "painting":     { /* painting object, see below */ },
  "scan":         { /* scan object, see below */ },
  "motif_image":  "path. Portrait-orientation hero crop.",
  "motif_caption":"string. Tag shown over the motif on the system page.",
  "hero_bg_image":"path. Wide landscape strip used as faded background.",
  "design_principles": {
    "use":  "bool. If true, system page renders a 'principles' section.",
    "note": "string. Reason for disabling, if disabled."
  },
  "measurements":      { /* measurements object, see below */ },
  "extraction_method": { /* methodology object, see below */ },
  "pigments":          [ /* array of 12 pigments, see below */ ],
  "themes":            { "dark": {...}, "light": {...} },
  "hotspots":          [ /* array of 8-12 hotspots, see below */ ]
}
```

## painting

```jsonc
{
  "title":         "English / conventional title",
  "title_native":  "Original-language title (used as eyebrow text on system page)",
  "artist":        "Artist name",
  "date_start":    "string -- left bound of date range. e.g. '1495' or 'c. 1503'.",
  "date_end":      "string -- right bound. Same format.",
  "location":      "Institution, City",
  "dimensions_cm": [width_in_cm, height_in_cm],
  "technique":     "freeform technique description",
  "current_state": "freeform condition / restoration note"
}
```

## scan

```jsonc
{
  "url":                  "Tile pyramid manifest path (assets/<id>.dzi). Generated by scripts/make_tiles.py.",
  "fallback_url":         "Single-image fallback path (assets/<id>_full.jpg). Used by lab.html and run_analysis.py.",
  "width":                <int>,    // actual pixel width of the scan
  "height":               <int>,    // actual pixel height
  "source":               "Attribution string for the scan.",
  "reference_scan_url":   "URL to higher-resolution scan even if not hosted here.",
  "free_url":             "URL of the public-domain version (Wikimedia, etc.).",
  "free_url_dimensions":  [<int>, <int>]   // dimensions of the free version
}
```

## measurements

Surfaced on the analysis page section 04. Run `scripts/run_analysis.py` to compute these from a source image.

```jsonc
{
  "centroid_x_pct":     <float, 0-100>,   // x-coordinate of subject centroid as % of width
  "centroid_y_pct":     <float, 0-100>,
  "horizon_y_pct":      <float, 0-100>,
  "vanishing_point_offset_px":           <float>,
  "golden_ratio_left_pct":  38.20,
  "golden_ratio_right_pct": 61.80,
  "global_luminance_mean":  <float, 0-255>,
  "global_luminance_std":   <float>,
  "pixel_count":            <int>,
  "estimated_original_pigment_survival_pct": <int, 0-100>,
  "restoration_years":      <int>,
  "restoration_range":      "string, e.g. '1978-1999'",
  "reference_scan_gigapixels":   <float>,
  "reference_scan_panoramas":    <int>,
  "peer_reviewed_decoded_papers": <int>
}
```

Most of these are specific to the AI-claims-vs-real-science framing. For straight art-historical deep dives, the fields are still useful: `peer_reviewed_decoded_papers` can become any "papers verifying the claim" count, etc. Or just leave at 0 and don't surface them.

## extraction_method

```jsonc
{
  "name":  "Human-readable name of the palette extraction algorithm.",
  "steps": [
    "Step 1 description",
    "Step 2 description",
    "..."
  ],
  "code_repo_path": "scripts/build_assets.py"
}
```

Rendered as the numbered pipeline on the system page.

## pigments

An array of 12 pigment objects (the lab page renders them in a 4-column grid; 12 fits cleanly).

```jsonc
{
  "name":              "Display name. Pick something evocative + technical.",
  "hex":               "#RRGGBB. The derived color. Auto-computed if you run build_assets.py with --refresh-palette.",
  "comment":           "One-line technical note.",
  "sample_region_pct": [x0, y0, x1, y1],   // 0..1 fractions of the source image
  "hue_range":         [low, high],         // 0..1, optional. null = unfiltered.
  "historical":        "Historical pigment identity. Lead white, ultramarine, vermillion, etc.",
  "sample_thumb":      "Auto-generated thumbnail path. Don't edit by hand."
}
```

**Wrap-around hue ranges:** for pigments that span red (which crosses hue=0), use `[0.95, 0.06]`. The runtime treats `low > high` as "hue >= low OR hue <= high."

## themes

```jsonc
{
  "dark":  { "name": "Display name", "subtitle": "Short tagline", "is_default": true },
  "light": { "name": "Display name", "subtitle": "Short tagline", "is_default": false }
}
```

The actual color values for each theme live in `tokens.css`. The config is just naming.

## hotspots

An array of 8-12 hotspot objects. The lab uses them as quick-select buttons; the explorer renders them as click-targets on the painting and as cards in the sidebar.

```jsonc
{
  "id":      "lowercase hyphenated slug. Used as URL hash anchor and thumbnail filename.",
  "name":    "Display name.",
  "region":  [x0, y0, x1, y1],   // 0..1 fractions
  "summary": "1-3 sentences. Shown in the explorer sidebar."
}
```

## Coordinate system

All `*_pct` values are 0-100 (humans read percentages).
All `region` and `sample_region_pct` values are `[x0, y0, x1, y1]` as 0..1 fractions (cleaner for the math).

`y` increases downward (top of image is y=0). `x` increases rightward.
